## 0. 范围与决策摘要

用户已确认并保留的内容：

1. **四种深色主题全部保留**：深海蓝灰、墨松绿、烟紫黑、暖烟棕；新增主题切换按钮，随时切换并持久化。
2. **收起态左侧竖向网络状态条保留**，语义沿用现有实现（绿 / 琥珀 / 红 / 灰）。
3. **新增 CC Switch 启动按钮**（仓库目前完全没有 CC Switch 代码，本项为新增能力）。
4. **呼吸灯**：只有“进行中”的状态呼吸；在线、空闲保持静态。
5. **音乐卡保留封面驱动的液态玻璃背景**，不跟随主题染色。
6. **插件设计**：Autoloop（三种状态）、天气（背景随天气状态）、时钟（更大更清楚）。

本报告不包含：真实数据接入、真实拉起点按、真实 Autoloop 传输。视觉稿中的数值为固定示例。

## 2. 设计原则

1. **卡片就是玻璃，没有外层底板。** 卡片之间直接露出桌面；不为整列加圆角容器。
2. **文字不透明，材质只作用于背景。** 透光、模糊、折射都只影响卡片底层；文字、图标、进度条保持清晰。
3. **状态不只靠颜色。** 网络、Agent、Autoloop、天气都同时给出文字或图标。
4. **动效克制。** 只有进行中的对象呼吸；其余静止。呼吸频率不低于 2 s。
5. **统一规范优先于现状。** 新组件一律使用本报告的 token；旧组件在改造时收敛。

| 档位 | 用途 |

| 12 | 说明、时间、状态、辅助信息 |
| 14 | 正文、指标、菜单项、任务名 |

## 6. CC Switch 启动按钮

仓库不存在 CC Switch，按现有外部程序启动模式实现：

- 位置：收起态右侧、展开态标题栏；24 px 图标按钮，提示“启动 CC Switch”。
- 探测顺序（与 `Find-AgentLaunch` 同构）：配置覆盖 `ccSwitchLaunch`（`.exe` 或 `.lnk`）→ 运行中进程（建议匹配 `cc-switch`、`CC Switch`、`ccswitch`，大小写不敏感）→ 开始菜单快捷方式 → Appx 包。禁止拼接用户未配置的任意路径。
- 点击：已有主窗口 → `[AgentWin]::Activate` 聚焦；否则 `Start-Process -FilePath`（`.lnk` 用 `UseShellExecute`）。
- 状态：常态；悬停提亮 + 提示；启动中 400 ms 内显示呼吸转圈并禁用重复点击；未检测到 → 40% 透明度禁用，提示“未检测到 CC Switch”。失败时不清空配置，记录一次错误并在悬停提示中说明。

## 7. 呼吸灯规范

| 元素 | 触发 | 节奏 | 形态 |
|---|---|---|---|
| Agent LED（8 px） | working / 运行中 | 2.4 s | 透明度 0.42→1，缩放 0.9→1.08 |
| 网络竖条 | warning / error | 4 s / 6 s | 透明度 0.5→1 |
| Autoloop 运行指示 | 存在运行中任务 | 2.4 s | 同 Agent LED |
| CC Switch 启动中 | 点击后 400 ms | 1.6 s | 转圈 + 呼吸 |

约束：不使用闪烁（频率 < 0.5 Hz 以上一律禁止）；系统“减少动态效果”或用户设置 `reduceMotion` 时全部静态、保持满亮度；呼吸仅表达“进行中”，不表达健康状态本身。实现上建议 10–15 fps 定时器只重绘 LED 区域，不整窗重绘。

## 8. 插件设计

### 8.1 Autoloop（设计建议，当前为静态占位卡）

- 未连接（现状，须保持语义）：`Autoloop` + 空心 LED “未连接” + “连接后显示任务” + “连接”入口。
- 运行中（建议）：标题 + 呼吸 LED “运行中”；最多 3 条任务（LED + 任务名 14 px + 右侧时间/排队 12 px）；底部“暂停全部 / 打开 Autoloop”。超过 3 条显示“+N 项”。
- 已完成：静态 LED “已完成” + “今日 3 项任务已完成” + “查看记录”。
- 高度：离线/完成 120 px；运行中 232 px。圆角 24。
- 边界：在传输与事件协议接入前，不得把该卡渲染为运行中；视觉稿仅为设计目标。

### 8.2 天气

- 卡面：城市 14 → 温度 32（显示档）→ 图标 + 状态文字 14 → 最高/最低 12 → 降水或能见度 12。
- 背景：天气状态渐变层叠加在玻璃上，透明度 42%；文字保持不透明。六种视觉：晴、多云、阴、小雨、小雪、雾。
- 现有枚举只有 Clear/Cloud/Rain/Snow；建议保持枚举兼容，背景选择规则：Clear→晴、Cloud→多云（描述含“雾”时用雾背景）、Rain→雨（文案“雷雨”时可加闪电小标）、Snow→雪、Unknown→中性灰。若扩展枚举，必须保留 Unknown 兜底。
- 空/错误：`unconfigured`→“请选择城市，不读取定位” + “选择城市”；`not-connected`→“尚未配置天气服务”；`invalid`→“天气数据无效”；失败码文案沿用现有集合（超时/限流/代理认证/证书/安全连接/数据异常/响应异常/连接失败/暂不可用）。不得用旧数据冒充实时。

### 8.3 时钟

- 目标：更大、更清楚。时间成为焦点，日期与星期退为辅助。
- A 方块 168 × 160（默认，与天气并排）：时间 32 px/600 + 日期 12 + 周数 12；右下 56 px 细刻度盘作装饰（不承载读时）。
- B 长条 408 × 120：时间 40 px + 右侧日期 14 / 城市 12；下方“第 45 周”胶囊。
- C 表盘 + 数字备选 168 × 160：88 px 表盘 + 32 px 数字。
- 每日刷新本地时间；秒不入画（避免每秒闪烁），如需秒点用静态微点。
- 字体单位：全部 `GraphicsUnit.Pixel`；不要沿用 8pt/22pt。

### 8.4 音乐

- 封面 64 × 64，圆角 24。
- 背景：封面 → 模糊 26 px → 亮度 0.5 → 暗罩 55%；不随主题染色。
- 曲名 16、歌手 14、歌词行 12；进度 4 px；时间 12；播放按钮 40 px 圆形，中性色。
- 封面缺失/失败：中性深色底 + 音符图标，不显示破图。

## 10. Codex 实施指南（GDI+ / 分层窗口）

1. **玻璃取样**：分层窗口无法使用系统背景模糊。用 `BitBlt` 从屏幕 DC 取卡片矩形并外扩 16–24 px 的区域，缩小 8 倍 → 高斯近似 → 放大，得到模糊层；再叠加主题染色、边缘折射（沿圆角 SDF 位移）、亮边/暗边与方向性高光。只在位置/尺寸/主题/壁纸变化或展开动画时重算，缓存到离屏 `Bitmap`；数据刷新只重绘文字与进度。
2. **性能**：一次全列重算目标 < 16 ms；展开动画期间可使用低分辨率模糊（4×）过渡；空闲时不重绘卡片背景。
3. **降级**：屏幕捕获失败（远程桌面、权限、Secure Desktop）→ 使用主题不透明渐变卡（`panel` 近似色 + 边缘高光），保证文字与状态可用；日志记录一次。
4. **单位**：所有字体构造显式 `GraphicsUnit.Pixel`；12/14/16/20/32/40。
5. **圆角**：统一 24（网络条、LED、表盘除外）；使用 `GraphicsPath` 圆角矩形，避免逐像素。
6. **主题**：把四个 `tintRgb/faceRgb/lightRgb/accent/tint/ink/secondary` 做成配置对象；切换时刷新缓存并写 `config.json` 的 `theme`。
7. **网络条**：保留现有 `StatusSignal` 判定与颜色 RGB；几何改为 4 × 48、圆角 4、left 12、垂直居中；增加 warning/error 呼吸（10–15 fps 局部刷新），读取失败保持 unknown 灰。
8. **CC Switch**：新增配置 `ccSwitchLaunch`；探测与启动复用 `Find-AgentLaunch` / `Open-AgentApp` 模式；不得执行用户未明确配置的任意程序。
9. **Autoloop**：在事件源与传输实现前保持离线占位；只预留状态枚举 `offline / running / done` 与渲染函数。
10. **无障碍**：呼吸尊重系统减少动效设置（读取注册表 `AnimationLevel` 或现有开关）；按钮均有 AccessibleName；网络条悬停提示含“正常/降级/断开 + 延迟”。

## 11. 风险与待决

1. **宽度变更**：344 → 360 会改变现有布局常量与 166 方块网格；若 Codex 选择保留 344，需把内边距降为 20 并复核文字是否挤压。
2. **屏幕取样权限与性能**：分层窗口 BitBlt 在远程桌面/高 DPI 下可能失败或变慢；必须实现降级与缓存。
3. **CC Switch 探测**：产品名与进程名未确认；按配置覆盖优先，禁止猜测安装路径自动执行。
4. **天气枚举**：雾/雷雨目前借 Cloud/Rain 表达；若扩展枚举，读取旧配置必须兼容。
5. **Autoloop**：仓库无传输协议；运行态为设计建议，不能作为“已实现”描述。
6. **字号单位**：现有 8pt/22pt 与 13px 混用；迁移必须逐处改为像素，避免视觉尺寸跳变。
